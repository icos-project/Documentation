ICOS Administration Guide
=====

**ICOS Meta OS** is a highly distributed system consisting of multiple nodes deployed across the Cloud-Edge continuum. 
A comprehensive overview of the ICOS architecture and its components can be found in deliverable ["D2.2 ICOS Architecture Design (IT-1)"](https://www.icos-project.eu/files/deliverables/D2.2_ICOS_Design_v1.0.pdf).
To establish a functional system, at least one [ICOS Controller](ICOS Controller/index.md) and one [ICOS Agent](ICOS Agent/index.md) are required. 
This section outlines the key requirements, as well as the installation and configuration steps necessary to set up an ICOS system from the ground up.
